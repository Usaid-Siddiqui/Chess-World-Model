# Phase 1 — AR baseline (Lichess 2016-04)

Clean, non-overfit reproduction of the Chess-GPT emergent board representation: a plain
next-move transformer, never shown a board, linearly encodes the true board at ~99%.

## Setup

- **Data**: Lichess `2016-04`, standard rated, both Elo ≥ 1600, ≥10 plies, ≤512 plies.
  ~1M games kept (`MAX_GAMES=1000000`), ~2% held out for val.
- **Model**: shared GPT backbone, ~25M params (8 layers / 512 dim / 8 heads), ctx 512,
  dropout 0.1. Weight-tied AR head, next-move cross-entropy.
- **Training**: bf16 + TF32 on A100 80GB. Data-relative schedule: **8 epochs → 20,408 steps**,
  batch 384, AdamW, cosine LR (peak 6e-4). ~2.1 h wall.

## Results

| Metric | Value |
|---|---|
| final train loss | 1.7268 |
| final val loss | 1.7275 |
| train/val gap | ~0.0007 (no overfitting) |
| majority-class probe baseline | 63.88% |
| **linear board probe (relative, layer -1)** | **99.01%** (+35.13 over baseline) |
| MLP board probe | 99.08% |
| linearity gap (MLP − linear) | **0.07 pts** |
| worst square | ~97.5% |

## Layer sweep (relative, val, 60k positions)

Linear board-probe accuracy at each layer (0 = after block 1, 8 = final `ln_f` output = `-1`):

| layer | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 (final) |
|---|---|---|---|---|---|---|---|---|---|
| linear % | 84.70 | 89.81 | 91.59 | 94.31 | 95.28 | 96.29 | 98.24 | 98.94 | **99.01** |

Baseline 63.88%. **Best = final layer 8**, MLP 99.06% → gap **0.06 pts**. Monotonic climb with
depth (no mid-stack peak); even layer 0 is +21 over baseline, so the board forms early and
sharpens through the stack. This is the AR arm's per-layer curve to compare JEPA against.

## Reading

- Train ≈ val → the epoch-driven schedule + dropout fixed the earlier 118-epoch overfit
  (which had train 0.20 / val 7.26 and probe only 80%).
- Linear ≈ MLP (0.07-pt gap) → the board is stored **linearly**, not tangled — matches
  Karvonen's finding that the relative (mine/yours) encoding makes the representation linear.
- 99.01% linear reproduces the published >99% relative-encoded linear probe. This is the
  reference bar the JEPA arm (Phase 2) will be compared against.
